# Healthcare Insurance ETL Testing & Data Reconciliation Project

## 1. Project Overview

This project demonstrates an end-to-end ETL Testing and Data Quality Validation process for a Healthcare Insurance Claims system.

The objective is to validate patient, hospital billing, and insurance claim data using SQL and Python. The project focuses on identifying data quality issues, validating business rules, detecting duplicate records, and performing source-to-target reconciliation.

## 2. Business Scenario

A healthcare organization receives data from three different source systems:

- Patient Management System
- Hospital Billing System
- Insurance Claims System

Before the data is used for reporting and business analysis, it must undergo ETL validation to ensure accuracy, completeness, consistency, and integrity.

## 3. Project Objectives

- Validate source and target record counts.
- Identify duplicate patient and claim records.
- Validate patient age and claim amounts.
- Identify missing and invalid values.
- Validate date formats and business rules.
- Verify referential integrity between tables.
- Perform source-to-target data reconciliation.
- Automate data validation using Python.
- Generate test execution and defect reports.
